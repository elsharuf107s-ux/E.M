02 — Approach

Boring stack, unusual pages.

The interesting decisions belong in the layout, not the toolchain. Every site here is hand-written HTML and CSS in one file, which makes it fast, portable and possible to hand over without a lecture.

i

The trade sets the layout

A plumber's site is a dispatch board because a burst pipe is a triage problem. A workshop's is a job card because the anxiety is the invoice. The structure argues the case before the copy does.

ii

Answer the question on the page

Prices, response times, timetables and stages are published rather than hidden behind a form. Every build has at least one section that tells a visitor something a competitor makes them phone for.

iii

One file, no dependencies

Styles, scripts and logo are inlined. Drop the file on any host — or open it straight off a USB stick — and it works. Nothing to install, nothing to rebuild, nothing that expires.

In every build Standard · 2026
  • Responsive from 320px to ultrawide, no horizontal scroll
  • Semantic landmarks, skip links and visible focus states
  • Page title, meta description, theme colour and Open Graph tags
  • Contact, enquiry or booking form wired to a real destination on handover
  • Logo embedded as a data URI — no broken image on a bad host
  • Motion respects prefers-reduced-motion
